# Slides

Talk decks for the workshop. Each deck is a self-contained
[reveal.js](https://revealjs.com) presentation that opens in a new tab.

| Deck | Description |
| --- | --- |
| [Introduction to Open-Source](decks/00-open-source.html) | What open-source is, why it matters in research, and where Bonsai and Harp come from. |
| [Introduction to Bonsai and Harp](decks/01-introduction.html) | What visual reactive programming is, how to read a Bonsai workflow, and an introduction to Harp at the end. |
| [Template deck](decks/template.html) | Empty starting point — copy this to begin a new talk. |

> [!NOTE]
> The Bonsai and Harp deck still has placeholder Harp slides at the end, and the
> best-practices talk has not been written yet.

## Presenting

- <kbd>F</kbd> — full screen
- <kbd>S</kbd> — speaker notes window
- <kbd>O</kbd> — slide overview
- <kbd>←</kbd> / <kbd>→</kbd> — move between topics, <kbd>↑</kbd> / <kbd>↓</kbd> — move within a topic

To print a deck to PDF, append `?print-pdf` to its URL and use the browser's
print dialog.

See [Authoring slides](authoring.md) for how to add a new deck.

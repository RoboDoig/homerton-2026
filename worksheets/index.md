# Worksheets

Hands-on exercises for the practical sessions. Work through them in order —
each one assumes the workflows built in the previous worksheet.

| Worksheet | Topic |
| --- | --- |
| [1 — Getting Started](01-getting-started.md) | Installing Bonsai and finding your way around the editor. |
| [2 — Acquisition and Tracking](02-acquisition.md) | Recording video and audio, and tracking a moving object. |
| [3 — Closed-Loop Systems](03-closed-loop.md) | Measuring closed-loop latency, and driving outputs from video. |
| [4 — Data Synchronization](04-synching.md) | Aligning video, stimuli and behaviour events; a reaction time task. |
| [5 — State Machines](05-state-machines.md) | Translating a trial structure into a workflow of states and events. |

Worksheets 3 to 5 use the Harp Hobgoblin. Set the board up first, following the
[Hobgoblin](../hobgoblin/index.md) section — it also explains what Harp registers are, and
which pins the exercises expect.

## Conventions

Throughout the worksheets:

- `CameraCapture` — a name in code font is an operator to insert in a workflow.
- **Exercise** headings mark something for you to build.
- Exercises marked *(Optional)* can be skipped if you are short on time.
